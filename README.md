# Analisis-de-Trades-Bursa-tiles-Mediante-Machine-Learning
El presente proyecto tiene como objetivo desarrollar y comparar distintos modelos de clasificación supervisada para predecir el resultado de operaciones bursátiles (trades) utilizando técnicas de Machine Learning en R.
Se implementaron y evaluaron cuatro enfoques principales: Regresión Logística, Máquinas de Soporte Vectorial (SVM), Árboles de Decisión, Bosques Aleatorios (Random Forest).
El propósito principal fue identificar qué modelo ofrece el mejor desempeño predictivo para clasificar operaciones ganadoras y perdedoras, considerando métricas como accuracy, sensibilidad, especificidad, AUC y balanced accuracy.
